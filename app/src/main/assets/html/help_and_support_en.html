Playback
External Players

If the external player has been started but no video is showing, check the following points:

  • The selected playback profile is not suitable. Recommended is 'matroska'.
  • The streaming port (default is 9981) is not correct.
  • The player can reach the server via the streaming port. Maybe the port is not properly forwarded by the router or a proxy.
  • Uploading the data from the server takes too long.
Internal Player

If the internal player has been started but no video is showing, check the following:

  • The selected playback profile is not suitable. Recommended is 'htsp'.
  • Uploading the data from the server takes too long.
Casting
Setup Transcoding

For maximum compatibility use a stream profile with the following settings:

  • Container: av-lib/MP4
  • Video codec: H.264, High profile
  • Audio codec: AAC LC profile
Setup TVHClientNG for casting
  • In the connection settings you can either use an IP-address or a DNS name for the connection.
  • Select the appropriate casting playback profile.
